# frontend

This template should help get you started developing with Vue 3 in Vite.

## ⭐ API Configuration (Important for Production)

**Before deploying to production, you MUST update the backend URL!**

See [API_SETUP_README.md](./API_SETUP_README.md) for complete documentation on:
- ✅ How to change backend URL for production
- ✅ Differences between development and production
- ✅ How the centralized API system works
- ✅ Complete list of 22 components that were refactored

**Quick Start:**
1. Edit `frontend/.env.production`
2. Replace `https://your-production-backend.com` with your actual backend URL
3. Run `npm run build`
4. Deploy the `dist/` folder
